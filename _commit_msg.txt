fix: Web Speech "tap Alt again does nothing / no text" — interim results + stop feedback

Root cause: recognition.continuous = true with interimResults = false. In Chrome/Edge,
continuous mode only finalizes results after a silence pause; tapping Alt to stop
mid-sentence makes stop() drop the un-finalized speech, so wsFinalText came back empty
and finishWebSpeech showed "未识别到文字". Meanwhile stopWebSpeech gave no immediate
feedback, so the status pill sat on "录音中" and the second tap felt dead.

- interimResults = true; onresult keeps the latest interim hypothesis (wsLastInterim)
- finishWebSpeech falls back to wsLastInterim when no final text was collected
- stopWebSpeech shows "⏳ 处理中…" immediately
- Tests 23 -> 25; lint + security clean
